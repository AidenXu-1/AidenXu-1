## 我在意的事

- **先理解需求**：动手之前，先弄清楚真正要解决的问题。
- **对结果负责**：文件生成了不等于事情完成了，结果需要能够使用和验证。
- **尊重真实边界**：公开版本、当前源码、本机安装和真实体验，各自都要说清楚。
- **持续学习**：工具会不断变化，理解力、判断力和学习能力可以持续积累。
